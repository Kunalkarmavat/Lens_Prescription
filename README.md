# 📱 Lens Prescription App

A scalable Flutter application designed to digitize and manage eye prescription records, providing a reliable and offline-first solution for users to access their vision data anytime.

---

## 🚀 Overview

Managing physical prescriptions can be inconvenient and error-prone. This app solves that by offering a secure local storage system with a clean architecture, ensuring fast performance and maintainability.

## ✨ Key Features

- Create, update, and delete prescription records  
- Persistent local storage using SQLite  
- Fast and offline-first experience  
- Modular and maintainable architecture (MVC)  
- Reactive UI updates with Provider  

---

## 🛠️ Tech Stack & Architecture

- Flutter – UI toolkit  
- sqflite (SQLite) – Local database  
- Provider – State management  
- MVC Architecture – Separation of concerns  

---

## 🏗️ Architecture Insight

The project follows MVC principles to ensure scalability and clean code:

- Loose coupling between UI and logic  
- Reusable components  
- Easy to extend and maintain
